## 公共文件

| 文件 | 作用 |
|---|---|
| 一键重绘全部.py | 在本文件夹或其完整副本中重绘全部图；`--recompute` 先调用附件正式 q1 程序重算 F1 余量扫描 |
| 自检.py | 副本重绘逐字节比较与匿名扫描，结果写入 自检结果.json |
| requirements.txt | Python 依赖版本 |
| lib/figkit.py | 公共样式（字体、配色、尺寸）、DEM 读取、式(15) 充电时间、CSV/PNG/SVG/meta 输出 |
| lib/labels.json | 全部图的记号与标签；正文改记号后只改此文件并重绘 |
| F01_余量敏感性/q1_rho_scan.py | 调用附件 src/q1_engine.py、src/dcore.py 重算余量扫描，输出 q1_rho_scan.json |
| F01_余量敏感性/q1_rho_reconcile.py | 与审核参照值对账，输出 F1_对账记录.md、q1_rho_reconcile.json |
| inputs/ | 冻结结果、原题数据、附件与审核参照的只读副本（未改动） |
